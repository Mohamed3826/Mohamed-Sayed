Full Vole Instruction Set (1 - C)

1RXY: Load Reg R from Mem XY
2RXY: Load Reg R with value XY
3RXY: Store Reg R to Mem XY (00 = Screen)
40RS: Move Reg R to Reg S
5RST: Add Two's Complement (S + T → R)
6RST: Add Floating-Point (S + T → R)
7RST: Bitwise OR (S | T → R)
8RST: Bitwise AND (S & T → R)
9RST: Bitwise XOR (S ^ T → R)
AR0X: Rotate Reg R right X bits
BRXY: Jump to XY if Reg R == Reg 0
C000: Halt execution
