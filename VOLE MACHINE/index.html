Program Instructions (Hex)

Quick Op-Code Reference

  • 1RXY: Load Reg R from Mem XY
  • 2RXY: Load Reg R with value XY
  • 3RXY: Store Reg R to Mem XY (00=Screen)
  • 40RS: Move Reg R to Reg S
  • 5RST: Add Reg S + Reg T into Reg R
  • BRXY: Jump to XY if Reg R == Reg 0
  • C000: Halt execution
